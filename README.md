- `/sq/` — Albanian portfolio
- `/en/` — English portfolio
- `/sq/cv-public.html` and `/en/cv-public.html` — privacy-safe public CVs

## GitHub Pages
Upload the entire folder contents to the repository root. GitHub Pages will serve `index.html`, which redirects to `/sq/`.

Before using a custom domain, replace `YOUR-DOMAIN` in `sitemap.xml`.
